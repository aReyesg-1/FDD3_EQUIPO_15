# EcoSmart 12

La pagina web actúa como el centro de control visual del sistema, enlazándose de manera inalámbrica (vía Wi-Fi) con el microcontrolador ESP32 
que recopila las lecturas de los 4 sensores usados para el proyecto.

La interfaz está construida con un enfoque moderno, minimalista y responsivo (utilizando paletas de colores basadas en tonalidades verdes y grises suaves que evocan la ecología y la tecnología limpia). Su navegación estructurada mediante un menú lateral estático permite al usuario saltar fácilmente entre el diagnóstico rápido de inicio y los gráficos detallados de control.
