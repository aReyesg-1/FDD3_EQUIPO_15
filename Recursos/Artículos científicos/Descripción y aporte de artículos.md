# Antecedentes Científicos

## Artículo Científico 1
### Beyond Composting Basics: A Sustainable Development Goals–Oriented Strategic Guidance to IoT Integration for Composting in Modern Urban Ecosystems (2024)

**Descripción:**
Este artículo presenta una revisión de las tecnologías de Internet de las Cosas (IoT) aplicadas al compostaje. Analiza el uso de sensores para medir variables como temperatura, humedad, pH y emisiones gaseosas, así como la integración de sistemas de monitoreo y automatización que permiten optimizar el proceso de descomposición de residuos orgánicos.

**Aporte al prototipo:**
Este trabajo respalda la incorporación de sensores en EcoSmart Compost para monitorear variables críticas del compostaje en tiempo real. Además, proporciona fundamentos sobre el uso de tecnologías IoT para mejorar la eficiencia del proceso y facilitar la visualización de datos ambientales.

## Artículo Científico 2
### Monitoreo y control de compostaje automatizado basadas en microcontroladores Raspberry Pi, sensores de gases, temperatura, pH, humedad y placas de desarrollo (2025)

**Descripción:**
El artículo recopila investigaciones relacionadas con sistemas automatizados de compostaje que emplean microcontroladores y sensores para medir temperatura, humedad, pH y gases generados durante la descomposición de la materia orgánica.

**Aporte al prototipo:**
Constituye una referencia para la selección de las variables que serán monitoreadas por EcoSmart Compost. Asimismo, justifica el uso de sensores de gases para detectar condiciones anómalas y mejorar el seguimiento del proceso de compostaje.

## Artículo Científico 3
### Design and Implementation of IoT-enabled Compost Monitoring System (2019)

**Descripción:**
Este estudio desarrolla e implementa un sistema de monitoreo de compostaje basado en Internet de las Cosas. El sistema permite recolectar datos ambientales mediante sensores y transmitirlos para su supervisión remota.

**Aporte al prototipo:**
Demuestra la viabilidad técnica de monitorear el compostaje en tiempo real mediante dispositivos electrónicos conectados. Además, sirve como referencia para el diseño de la arquitectura de adquisición y transmisión de datos de EcoSmart Compost.

## Artículo Científico 4
### Compost Maturity Prediction and Gas Emissions Monitoring: A Sensor-Based and Interpretable Machine Learning Approach (2025)

**Descripción:**
La investigación propone un sistema basado en sensores y modelos de aprendizaje automático para monitorear emisiones gaseosas y predecir la madurez del compost durante las diferentes etapas del proceso.

**Aporte al prototipo:**
Este trabajo respalda la estimación automática de la etapa de compostaje a partir de los datos recopilados por los sensores. También proporciona fundamentos para la generación de alertas cuando las condiciones del compost se alejan de los valores esperados.

## Artículo Científico 5
### Education and Sustainability: A Model for Different Engineering Degrees (2024)

**Descripción:**
El artículo presenta una experiencia educativa que integra tecnologías IoT, huertos y compostaje en la formación de estudiantes universitarios, promoviendo el aprendizaje de la sostenibilidad y la gestión ambiental.

**Aporte al prototipo:**
Constituye un antecedente que justifica el uso de EcoSmart Compost como herramienta educativa. Demuestra que los sistemas de monitoreo ambiental pueden utilizarse para fortalecer el aprendizaje sobre compostaje, sostenibilidad y análisis de datos en instituciones educativas.
