1. Implementación de actuadores y sensores inalámbricos en contenedor casero para el control y monitoreo del proceso de compostaje

Descripción:
Esta tesis desarrolla un sistema de monitoreo y control para el proceso de compostaje mediante el uso de sensores y actuadores inalámbricos conectados a una plataforma de supervisión. El sistema permite medir variables ambientales relevantes para el compostaje y transmitir la información en tiempo real, facilitando el seguimiento de las condiciones internas del proceso y mejorando su eficiencia mediante tecnologías de comunicación inalámbrica.

Aporte al proyecto EcoSmart-12:
Esta investigación aporta conocimientos sobre la integración de sensores, actuadores y tecnologías de comunicación inalámbrica aplicadas al compostaje. Además, sirve como referencia para el desarrollo del sistema de monitoreo remoto de EcoSmart-12, permitiendo la supervisión continua de las variables ambientales y la optimización de las condiciones necesarias para una adecuada descomposición de los residuos orgánicos.

2. Prototipo de un compostador de uso doméstico automatizado con Arduino

Descripción:
Esta tesis presenta el diseño y desarrollo de un compostador automatizado para uso doméstico basado en tecnología Arduino. El sistema incorpora sensores para monitorear variables como temperatura y humedad, además de mecanismos que permiten automatizar procesos relacionados con la aireación y el mantenimiento de las condiciones necesarias para la producción de compost.

Aporte al proyecto EcoSmart-12:
Esta investigación proporciona una base para la automatización de procesos dentro del compostaje, así como para la integración de sensores y dispositivos electrónicos en un sistema inteligente. Asimismo, aporta criterios de diseño relacionados con el control de las condiciones ambientales y la reducción de la intervención manual durante el proceso de compostaje, aspectos que son considerados en el desarrollo de EcoSmart-12.

3. Desarrollo de un dispositivo IoT Cloud para la elaboración y monitoreo de compostaje en invernaderos caseros

Descripción:
Esta tesis desarrolla un dispositivo IoT para la elaboración y monitoreo de compostaje en invernaderos caseros mediante una red inalámbrica. El sistema utiliza sensores de temperatura, humedad y pH conectados a un módulo ESP8266, el cual transmite los datos hacia una plataforma digital para su visualización en tiempo real a través de una aplicación móvil. Además, incorpora herramientas de diseño y monitoreo que facilitan el seguimiento continuo del proceso de compostaje.

Aporte al proyecto EcoSmart-12:
Esta investigación aporta una referencia importante para la implementación de tecnologías IoT en EcoSmart-12, especialmente en lo relacionado con la adquisición de datos, la comunicación inalámbrica y la visualización remota de información. Asimismo, proporciona criterios para el monitoreo en tiempo real de variables ambientales mediante sensores y plataformas digitales, contribuyendo al desarrollo de un sistema inteligente para la gestión y seguimiento del compostaje.
